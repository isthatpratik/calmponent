Calmponent uses the same CSS variable names as shadcn/ui. If you already have a shadcn theme, Calmponent components use it.

## Color

Full monochrome. Color appears only for status: `--destructive`, `--success`, and `--warning`. shadcn/ui has no `--success` or `--warning`, so Calmponent adds them.

Every text color passes WCAG AA (4.5:1). Input borders and focus rings pass 3:1. A script checks this on every pull request.

## Type

Geist for text and Geist Mono for code. Text styles such as `heading-1`, `body-6`, and `caption-3` sit on the Tailwind type scale. Headings use tight tracking (`-0.025em`).

## Radius

`--radius` is 8px. Buttons and inputs use `rounded-lg` (8px), and cards use `rounded-xl` (12px).

## Motion

One curve, `ease-calm`: `cubic-bezier(0.22, 1, 0.36, 1)`. Use `duration-200` for color and opacity, `duration-300` for state changes, and `duration-500` for layout. With reduced motion, movement becomes a fade.
