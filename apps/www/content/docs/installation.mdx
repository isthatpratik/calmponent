title: Installation
description: Add Calmponent items to your project with the shadcn CLI.
---

Calmponent works with the shadcn CLI. You need React 19 and Tailwind CSS 4.

Add the `cn()` helper, which every Calmponent component uses:

<InstallCommand item="isthatpratik/calmponent/utils" />

To pin a release, add a tag, for example `isthatpratik/calmponent/utils#v0.0.1`.

The shorter `@calmponent/utils` form comes later, when the docs site is hosted.
