## Parts

The same names as the shadcn/ui tabs: `Tabs`, `TabsList`, `TabsTrigger`, and `TabsContent`.

- `TabsList` takes `variant`: `"default"` (a sliding pill) or `"line"` (a sliding underline).
- `TabsTrigger` takes `value` and `disabled`.
- `TabsContent` takes `value` and `loading`, which shows skeleton lines shaped like content.

## Accessibility

- Base UI handles the tablist roles: arrow keys move between tabs, and disabled tabs are skipped.
- A loading panel sets `aria-busy`.
- With reduced motion, the highlight jumps instead of sliding, and panels fade without moving.
