```tsx
</Field>
```

## States

<CheckboxStates />

## Props

Every Base UI `Checkbox.Root` prop: `checked`, `defaultChecked`, `onCheckedChange`, `indeterminate`, `disabled`, `required`, and `name`.

## Accessibility

- The checkbox has `role="checkbox"` and `aria-checked`, including `"mixed"` for indeterminate.
- With reduced motion, the check and the dash appear without drawing.
