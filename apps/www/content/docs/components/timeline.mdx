## Parts

- `Timeline`: an ordered list. Takes `loading` (skeleton rows shaped like items), `loadingRows` (default `3`), and `empty` (shown when there are no items).
- `TimelineItem`: takes `status` (`"done"`, `"running"`, `"pending"`, `"failed"`, or `"skipped"`), `title`, `description`, `time`, and `duration`.

## Accessibility

- The timeline is an ordered list, so screen readers announce the number of steps.
- Each item adds its status as hidden text, for example "Build, Done", so color is never the only signal.
- The running item has `aria-current="step"`.
- With reduced motion, the line fills without drawing, icons appear without popping, and the skeleton does not pulse.
