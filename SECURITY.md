# Security policy

If you find a security problem in Calmponent, tell us privately. Do not open a public issue.

## How to report

Use GitHub private vulnerability reporting:

1. Go to the [Security tab](https://github.com/isthatpratik/calmponent/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected component or file, and the steps to reproduce it.

We will reply as soon as we can. We will tell you when the problem is fixed, and we will credit you in the release notes if you want.

## Supported versions

Calmponent has no release yet. When releases start, only the latest version gets security fixes.
